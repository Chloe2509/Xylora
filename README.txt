XYLORA — FILES TO UPLOAD

Upload ALL of these files into the same GitHub Pages folder:
1. index.html       = Login / Sign Up page (FIRST PAGE)
2. builder.html     = Profile setup / builder
3. style.css        = Styling
4. auth.js          = Login, Sign Up, Discord authentication
5. script.js        = Profile builder functions
6. xylora-login-background.png = Login page background

The visitor opens:
Xylora → index.html (Login / Sign Up)
After successful login → builder.html (Profile Setup)

IMPORTANT:
For email/password authentication, your Supabase project must have Email authentication enabled.
For Discord, configure Discord as a Supabase OAuth provider and add your GitHub Pages URL as an allowed redirect URL.
