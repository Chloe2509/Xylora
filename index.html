🌌 XYLORA — COMPLETE PLAN 🪐 1. What Xylora is Xylora is a profile-platform where anyone can create their own personalized profile. A user gets a profile like: xylora.com/@username Their profile can contain: 👤 Profile picture ✍️ Name @ Username 📝 Bio 🔗 Links 🎵 Music 🖼️ Photos 🎥 Videos 📁 Files 💼 Work 🎮 Gaming 🌎 Communities 📊 Stats And much more The main idea is: Your profile. Your layout. Your identity. 🔐 2. Account system The flow is: Xylora → Log in / Sign up → Profile Builder → Your profile Users can create an account with: 📧 Email + password 🎮 Discord Google Users do not need GitHub to use Xylora. 🎨 3. Profile builder The builder lets users customize basically everything. Profile basics Display name Username Bio Profile picture Background Fonts Colors Gradients Positioning Everything can be moved independently. For example: Name can be here Username somewhere else Bio somewhere else Music somewhere else Links somewhere else Users aren't forced into one rigid layout. 🧩 4. Profile blocks Users can add blocks such as: Text Links Music Gallery Video Files Guestbook Stats Countdown Game Socials Custom blocks Eventually blocks can be: Moved Resized Rotated Duplicated Deleted Grouped 🌌 5. Themes There will be theme presets such as: 🌌 Galaxy 🌈 Aurora 🌊 Ocean 🌅 Sunset 🤖 Cyber ⚪ Minimal But users aren't locked into a theme. They can customize individual parts themselves. ✨ 6. Effects system This was an important decision: Free users get real effects. They aren't forced to have a boring profile. Xylora Worlds This is one of the bigger ideas. Instead of having only one profile, users could have connected Worlds. For example: 🌎 Main World Their main profile. 🎵 Music World Music and playlists. 🎨 Art World Artwork and galleries. 🎮 Gaming World Games, achievements, gaming profiles. 💼 Projects World Projects and work. 📁 Files World Downloads and files. So Xylora becomes more than just a profile page. 🧬 18. Profile DNA Every profile could develop its own unique visual identity based on the user's: Colors Fonts Effects Layout Blocks Background Style The goal is for two Xylora profiles to feel completely different. 🗺️ 19. Custom CSS This is planned as a Premium feature for people who want extremely advanced customization. 💎 31. Premium The Premium system we settled on is: 🆓 Free The core Xylora experience stays usable for free. 💎 Premium Users get things like: Animated profile pictures Advanced backgrounds Advanced effects More fonts More colors/styles Advanced animations More customization Advanced blocks Analytics Custom CSS More storage Custom profile domain Remove Xylora branding Premium trial 4-month free trial After that, the plan we most recently settled on was: $15 one-time payment → Premium forever. ✦ 32. Xylora branding This is the feature we just worked on. Free profile At the bottom: ✦ Made with Xylora ✦ Premium profile Premium users can remove it. So Premium can look like: This is completely my profile. while Free profiles still have a small Xylora connection. 📱 33.
